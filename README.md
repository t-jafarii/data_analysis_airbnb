# Airbnb Data Analysis 🏠

This project was created for **educational and practice purposes** as part of a Data Analysis course.

The Airbnb dataset was used to practice and apply the concepts and techniques that were taught throughout the course.

## 🎯 Project Purpose

The main purpose of this project was to reinforce the course materials through hands-on practice, including:

* Data cleaning and preprocessing
* Data exploration and analysis
* Working with **Pandas** and **NumPy**
* Data visualization using **Matplotlib**
* Exploring relationships between variables
* Extracting insights from data

## 🛠️ Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## 📌 Note

This is an **educational project** created to practice and demonstrate the concepts covered during the course. The analyses and visualizations were performed primarily for learning and hands-on experience.
